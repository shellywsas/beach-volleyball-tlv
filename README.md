# כ"ח תל אביב - אפליקציית ניהול טורנירי כדורעף חופים 🏐
**העמותה לכדורעף חופים ע"ש רועי פלס**

אפליקציה מתקדמת, פשוטה, אינטואיטיבית ומותאמת במיוחד לטלפון נייד (סמארטפון) ולמחשב.
פותחה במיוחד עבור מועדון כדורעף חופים כ"ח תל אביב בעיצוב הרשמי ובצבעי המועדון (ורוד חופים, נייבי, טורקיז וצהוב).

---

## ✨ תכונות עיקריות

1. **הקמה קלה ומהירה של טורניר**:
   - מתאימה לכל אדם - גם ללא רקע טכנולוגי כלל.
   - קביעת כותרת הטורניר (למשל: "טורניר שישי חופים - רמה א'").
   - בחירת כמות הבתים (בית א', בית ב', בית ג'...).
   - **גמישות מלאה בכמות הזוגות בכל בית**: ניתן לקבוע כמות זוגות שונה לכל בית (למשל בית א' עם 3 זוגות, ובית ב' כבית חריג עם 4 זוגות).
   - הזנת שמות 2 השחקנים בכל זוג.
   - כפתור "מילוי שמות לדוגמה" לבדיקה מהירה של האפליקציה בשניה אחת!

2. **שלב הבתים - 2 אפשרויות מובנות**:
   - **אופציה 2 (מובנה ואוטומטי - מומלץ)**:
     - כל הזוגות משחקים מול כל הזוגות (Round Robin).
     - בבית של 3 זוגות:
       - משחק 1: זוג 1 מול זוג 3
       - משחק 2: זוג 2 מול זוג 3
       - משחק 3: זוג 1 מול זוג 2
   - **אופציה 1 (בחירה ידנית)**:
     - שליטה ידנית מלאה על סדר המשחקים, הוספת משחקים ידנית ושיוך מגרשים.

3. **לוח משחקים ועדכון תוצאות נוח על החול**:
   - כפתורי `+1`, `-1` ו-`+5` ענקיים וברורים המותאמים למגע בסמארטפון תחת השמש.
   - סימון מיידי של הזוג המנצח (גביע ירוק) וקונפטי חגיגי בסיום משחק.
   - אפשרות לערוך תוצאה מחדש בכל רגע במקרה של טעות.

4. **טבלאות בתים ודירוג חי בזמן אמת**:
   - חישוב אוטומטי של מקומות 1, 2, 3 (מדליות 🥇 🥈 🥉).
   - טבלה מלאה: משחקים ששוחקו, ניצחונות, הפסדים, נקודות זכות, חובה והפרש נקודות (+/-).
   - **כפתור "העתק סיכום לוואטסאפ"**: מעתיק בלחיצה אחת הודעה מעוצבת ומוכנה לשליחה ישירה לקבוצת הוואטסאפ של השחקנים!

5. **סנכרון ענן (Firebase) בין כל המכשירים + עבודה אופליין**:
   - עובדת חלק ובאופן מלא בדפדפן (LocalStorage) גם בלי שום הגדרה.
   - חיבור קל ל-Google Firebase Firestore לסנכרון חי: שופט או מנהל מעדכנים תוצאה בטלפון על המגרש, וכל המחשבים והטלפונים של השחקנים רואים את התוצאה והטבלה מתעדכנת מיידית!
   - קישור ישיר לטורניר עם קוד קצר (למשל `?t=TLV-1234`).

## 🌐 העלאה ל-GitHub (גיטהאב)

אם ברצונכם להעלות את הפרויקט לחשבון ה-GitHub שלכם:

1. היכנסו ל-GitHub ופתחו מאגר (Repository) חדש בשם `beach-volleyball-tlv`.
2. הריצו בטרמינל בתיקיית הפרויקט:
```bash
git remote add origin https://github.com/<המשתמש-שלכם>/beach-volleyball-tlv.git
git push -u origin main
```
או באמצעות GitHub CLI:
```bash
gh auth login
gh repo create beach-volleyball-tlv --public --source=. --remote=origin --push
```
